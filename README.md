# Verilog Combinational Circuits

This repository contains Verilog HDL implementations of various combinational digital circuits.

## Projects Included

- Half Adder
- Full Adder
- Ripple Carry Adder
- 4:1 Multiplexer
- Decoder
- Encoder
- Comparator

## Tools Used

- Verilog HDL
- Icarus Verilog
- GTKWave
- VS Code

## Simulation Flow

1. Write RTL design using Verilog
2. Create testbench for verification
3. Compile using Icarus Verilog
4. Analyze waveforms using GTKWave

## Objective

To understand RTL design concepts and develop a foundation for VLSI design and verification.
